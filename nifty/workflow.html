Cron Schedule

All scheduled jobs — times in IST (24h), weekdays only.

# Always running — Telegram control bot + watchdog every 5 min
@reboot        screen -dmS telegram_bot python telegram_bot.py
*/5 * * * *   watchdog — restarts telegram_bot if not running

# Token reminder — 7:30 AM weekdays (just open kite.zerodha.com and log in — CF Worker does the rest)
30 7 * * 1-5  python3 send_token_reminder.py

# token_receiver.py Flask server — always running, receives auto-captured token from Cloudflare Worker
@reboot        screen -dmS token_receiver python3 token_receiver.py

# ── MANUAL TOKEN BACKUP (if Cloudflare Worker fails) ────────────────
# 1. Open kite.zerodha.com → login → copy request_token from redirect URL
# 2. Send via Telegram: /token <request_token>
# 3. telegram_bot.py calls token_updater.py which writes to .env
# Normal flow (Cloudflare): login → CF Worker auto-POSTs to token_receiver.py → done

# Token validator — 9:15 AM weekdays
15 9 * * 1-5  python3 validate_token_at_915.py

# Health check — 9:20 AM weekdays
20 9 * * 1-5  python3 health_check_telegram.py

# Instance 1 — ORB Strategy (DRY) — starts 9:25 AM, entry 9:45–10:50
25 9 * * 1-5   INSTANCE_ID=1 screen -S bot_instance_1 -d -m python3 main.py

# Instance 2 — Breakout Strategy (LIVE) — starts 10:55 AM, entry 11:00–12:30
55 10 * * 1-5  INSTANCE_ID=2 screen -S bot_instance_2 -d -m python3 main.py

# Instance 3 — Mean Reversion Strategy (DRY) — starts 1:25 PM, entry 13:30–14:30
25 13 * * 1-5  INSTANCE_ID=3 screen -S bot_instance_3 -d -m python3 main.py

# Decision report — 7:00 PM weekdays
0 19 * * 1-5  run_daily_decision_report.sh

# Kill safety net — 8:00 PM (cleans up any hung processes)
0 20 * * 1-5  pkill -f "INSTANCE_ID=.*main.py"

Telegram Commands

Remote control — works on all running instances simultaneously.

# Status & Health
/status       → All instances: strategy, mode (DRY/LIVE), position, capital
/health       → Quick instance health check
/healthcheck  → Full system: token, funds, locks, panic files
/positions    → Open positions from broker

# P&L
/pnl          → Today's P&L (live from broker)
/pnlall       → All-time P&L (from trade logs)

# Instance Control
/kill 1       → Pause instance (no new trades)
/resume 1     → Resume paused instance
/revive 1     → Restart dead instance process
/killall      → Pause all instances
/resumeall    → Resume all instances

# Risk Control
/squareoff 1  → Force close position for instance
/panic        → Emergency exit all positions + stop all bots

# Token — manual fallback only (token is normally auto-captured via Cloudflare Worker)
/token <request_token>  → Manual token update (fallback if CF Worker fails)

Strategy Timeline

Daily market phase segmentation across 3 instances.

TIME        INSTANCE   STRATEGY     MODE    ACTIVITY
─────────────────────────────────────────────────────────────
09:15–09:45  Inst 1    ORB          DRY     Define opening range high/low
09:45–10:50  Inst 1    ORB          DRY     Watch for range break → enter CE/PE
10:50        Inst 1    ORB          DRY     Force exit — hand off capital to Breakout
10:55–11:00  ALL       —            —       Dead zone — no entries
11:00–12:30  Inst 2    Breakout     LIVE    Prev day high/low break → enter
12:30–13:30  Inst 2    Breakout     LIVE    Manage open position only
13:30–14:30  Inst 3    Mean Rev     DRY     Failed breakout → enter opposite
14:30–15:15  ALL       —            —       Manage open positions only
15:15        ALL       —            —       Force exit all positions

EXIT PRIORITY (checked in this exact order every loop):
  0. Momentum exit — 10–15 min after entry, spot move < 0.15% → exit early  ← Breakout only
  1. Target hit (+50%)
  2. Reversal exit — index crosses breakout level + 0.1% buffer (min 120s hold)
  3. Trailing SL — activates once profit ≥ risk amount, trails below peak
  4. Stop loss (-25%)
  5. Time exit — held ≥ 90 min (fallback only)
  6. Force exit — wall clock ≥ 15:15 (hard close, no exceptions)
